# Vocabra 📚

Vocabra is a premium vocabulary-building application designed to make learning new words simple, intuitive, and visually engaging. Powered by AI, it helps you discover, understand, and master new language concepts with ease.

## ✨ Features

- **AI-Powered Insights**: Get simple, easy-to-understand meanings and context for any word using Google Gemini.
- **Smart Dictionary**: Integrated dictionary lookup for formal definitions and phonetic pronunciations.
- **OCR Support**: Extract text from images or camera feed to quickly look up unfamiliar words.
- **Beautiful UI**: A modern, premium design with smooth animations and a focus on user experience.
- **Vocabulary Tracking**: Save and organize your personal lexicon for long-term retention.

## 🚀 Getting Started

### For Users
To simply use the app on your Android device:
1. Go to the [Releases](https://github.com/santhoshsunkara24/Vocabra/releases) section.
2. Download the latest `app-release.apk`.
3. Install it on your phone (you may need to "Allow from this source" in your settings).

### For Developers
If you want to contribute or build the app from source:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/santhoshsunkara24/Vocabra.git
   ```
2. **Install dependencies**:
   ```bash
   flutter pub get
   ```
3. **Run the app**:
   ```bash
   flutter run
   ```
